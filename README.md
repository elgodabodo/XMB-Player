## Installation & Running

### 🐧 Linux
1.  **Download:** Grab the latest `.AppImage` from the [Releases](link-to-releases) page.
2.  **Make Executable:** Right-click -> Properties -> Permissions -> Check "Allow executing file as program."
3.  **Run:** Double-click and it just works.

### 🪟 Windows
1.  **Download:** Grab the `.exe` from the [Releases](link-to-releases) page.
2.  **Move:** into any folder. It's fully portable.
3.  **Run:** Open the folder and run the application.

## ⚡ Key Features

| Feature | Description |
| :--- | :--- |
| **🎮 Mostly Controller Compatible** | Plug-and-play support for PlayStation (DualShock/DualSense) and Xbox controllers with dynamic, native button prompts ($A/\times$, $B/\bigcirc$, etc.) matching your layout. |
| **🎛️ Local Media Hub** | Add and organize your own music and video collections (mp3, wav, flac, mp4, etc.). |
| **🚀 App & Command Launcher** | Configure custom options to launch your favorite applications or execute system terminal commands directly from the dashboard. |
| **✨ Visualizers** | Get real-time, responsive audio visualizers that sync with your local audio. |
| **🎤 Lyrics & Syncing** | Load and sync lyrics for your local tracks. |
